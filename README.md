# Akshat Rawat — Selected Works (2026 Edition)

An editorial, tactile portfolio exploring digital craft, systems architecture, and physical-digital interactions. Built with high-performance vanilla styling, procedural shaders, and kinetic choreography.

---

## Highlights

- **Architectural Incision Loader**: Precision dual-curtain shutter reveal with live telemetry counter and ember filament flare.
- **Editorial Zine Identity**: Vintage warm paper textures, bespoke editorial typography, and interactive marginalia notes.
- **Kinetic Deck**: Spatial 3D tilt cards with tactile physics, foil light sweep, and dual-state architecture dossiers.
- **Archival Dispatch**: Web Audio API mechanical typewriter feedback and client-side encoded contact workflow.
- **Local-First Craft**: Zero bloated CSS frameworks; authored with pure Vanilla CSS, GSAP, Three.js, and Vite.

---

## Tech Stack

- **Core**: HTML5, Vanilla CSS3, JavaScript (ES Modules)
- **Tooling**: [Vite](https://vitejs.dev/)
- **Animation & Choreography**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger)
- **3D & Shaders**: [Three.js](https://threejs.org/)
- **Audio Feedback**: Web Audio API & Howler.js

## Local Development

```bash
# Clone the repository
git clone https://github.com/<YOUR-USERNAME>/portfolio.git

# Navigate into directory
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

---

## Production Build

```bash
npm run build
npm run preview
```
